# Правила добавления фильмов и сериалов в Telegram-хранилище

Этот документ нужен для админов, которые загружают видео в закрытый Telegram-канал KINOLINK.

Задача админа простая:

1. Загрузить видео в закрытый канал.
2. Правильно заполнить подпись к видео.
3. Проверить через бота, что видео появилось в Telegram-просмотре.

Бот сам получает `file_id` от Telegram и сохраняет связь:

```text
IMDb ID + тип контента + сезон + серия + озвучка -> Telegram-видео
```

## Главное правило

Каждое видео должно быть отдельным постом в закрытом канале.

Для фильма:

```text
1 пост = 1 фильм в 1 озвучке
```

Для сериала:

```text
1 пост = 1 серия в 1 озвучке
```

Если у фильма или серии несколько озвучек, каждую озвучку нужно загрузить отдельным постом.

## Обязательные поля

В подписи обязательно должны быть:

```text
Тип
Название
Год
Озвучка
IMDb
```

Для сериалов дополнительно обязательно:

```text
Сезон
Серия
```

IMDb ID должен быть именно в формате:

```text
tt0371746
```

Без IMDb ID бот не сможет связать видео с карточкой фильма из поиска.

## Шаблон для фильма

Скопируй этот шаблон и замени данные:

```text
Тип: Фильм
Название: Название фильма
Год: 2025
Озвучка: RHS
IMDb: tt0000000
```

Пример:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

Еще пример:

```text
Тип: Фильм
Название: Оно
Год: 2017
Озвучка: Профессиональный дубляж
IMDb: tt1396484
```

## Шаблон для сериала

Скопируй этот шаблон и замени данные:

```text
Тип: Сериал
Название: Название сериала
Год: 2025
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt0000000
```

Пример:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt3749900
```

Еще пример:

```text
Тип: Сериал
Название: Пацаны
Год: 2019
Сезон: 1
Серия: 2
Озвучка: LostFilm
IMDb: tt1190634
```

## Как добавлять несколько озвучек

Если один и тот же фильм есть в двух озвучках, загрузи два поста.

Пост 1:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

Пост 2:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: Дубляж
IMDb: tt0371746
```

В боте пользователь увидит выбор озвучки.

## Как добавлять серии

Каждая серия загружается отдельным постом.

1 серия:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt3749900
```

2 серия:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 2
Озвучка: RHS
IMDb: tt3749900
```

Если все заполнено правильно, в боте пользователь сможет выбрать:

```text
Сериал -> Сезон -> Серия -> Озвучка
```

## Что будет, если загрузить тот же фильм повторно

База обновляет запись, если совпадают:

```text
IMDb
Тип
Сезон
Серия
Озвучка
```

Например, если повторно загрузить:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

То бот не создаст дубль, а обновит видео на новый пост.

## Как проверить, что видео добавилось

1. Открой бота.
2. Нажми `🎬 Найти фильм`.
3. Введи то же название, которое указано в подписи.
4. Выбери нужный фильм или сериал.
5. Нажми `▶️ Смотреть в Telegram`.
6. Проверь, что появилась нужная озвучка.
7. Нажми на озвучку и убедись, что бот отправил видео.

Для фильма проверка выглядит так:

```text
Найти фильм -> Железный человек -> Смотреть в Telegram -> RHS -> видео отправилось
```

Для сериала проверка выглядит так:

```text
Найти фильм -> Готэм -> Смотреть в Telegram -> 1 сезон -> 1 серия -> RHS -> видео отправилось
```

Если нужной озвучки, сезона или серии нет в выборе, значит видео не добавилось или подпись заполнена неправильно.

Если бот пишет, что Telegram-версия пока недоступна, проверь подпись к видео и попробуй загрузить пост заново.

## Частые ошибки

### Ошибка 1. Не указан IMDb

Плохо:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
```

Хорошо:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

### Ошибка 2. Для сериала забыли сезон или серию

Плохо:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Озвучка: RHS
IMDb: tt3749900
```

Хорошо:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt3749900
```

### Ошибка 3. Неправильный IMDb ID

Плохо:

```text
IMDb: 3749900
```

Хорошо:

```text
IMDb: tt3749900
```

### Ошибка 4. Бот не добавлен в канал

Бот должен быть администратором закрытого канала.

Если бот не видит посты канала, видео не появятся в боте.

### Ошибка 5. Видео загружается не в тот канал

Видео нужно добавлять именно в закрытый канал-хранилище, к которому подключен бот.

Если ты загрузил видео, но в боте оно не появилось, проверь:

```text
[ ] Это точно правильный закрытый канал
[ ] Бот есть в этом канале
[ ] Бот добавлен администратором
```

Если все верно, но видео не появляется, сообщи ответственному за бота: возможно, канал неправильно подключен в настройках.

### Ошибка 6. Видео добавили, пока бот был выключен

Бот видит только новые посты, которые появились в канале, пока он работает.

Если фильм загрузили, пока бот не работал, он может не появиться в боте.

Решение:

1. Запустить бота.
2. Убедиться, что он работает.
3. Перезалить видео или переслать его в канал как новый пост с правильной подписью.

## Важное про file_id

`file_id` создает Telegram автоматически. Админ его не пишет вручную и нигде не ищет.

Достаточно правильно загрузить видео в закрытый канал и заполнить подпись по шаблону.

Бот сам сохранит нужные данные и потом сможет отправить это видео пользователю.

Поэтому нельзя удалять оригинальные видео из закрытого канала.

## Мини-чеклист перед загрузкой

Перед публикацией проверь:

```text
[ ] Видео загружается в правильный закрытый канал
[ ] Бот добавлен в канал админом
[ ] В подписи есть Тип
[ ] В подписи есть Название
[ ] В подписи есть Год
[ ] В подписи есть Озвучка
[ ] В подписи есть IMDb в формате tt...
[ ] Для сериала есть Сезон
[ ] Для сериала есть Серия
```

Если все пункты выполнены, видео должно автоматически появиться в Telegram-просмотре бота.
