# Инструкция для загрузки фильмов и сериалов в KINOLINK

Эта инструкция для админов, которые добавляют видео в закрытый Telegram-канал.

Главное: видео нужно загрузить в канал и правильно заполнить подпись. После этого бот сам добавит видео в Telegram-просмотр.

## 1. Основные правила

- Один пост = одно видео.
- Для фильма: один пост = один фильм в одной озвучке.
- Для сериала: один пост = одна серия в одной озвучке.
- Если есть несколько озвучек, каждую озвучку нужно загрузить отдельным постом.
- Нельзя удалять оригинальные видео из закрытого канала.
- Подпись нужно заполнять строго по шаблону.

## 2. Шаблон для фильма

```text
Тип: Фильм
Название: Название фильма
Год: 2025
Озвучка: Название озвучки
IMDb: tt0000000
```

Пример:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

## 3. Шаблон для сериала

```text
Тип: Сериал
Название: Название сериала
Год: 2025
Сезон: 1
Серия: 1
Озвучка: Название озвучки
IMDb: tt0000000
```

Пример:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt3749900
```

## 4. Как добавлять несколько озвучек

Если один фильм есть в двух озвучках, нужно загрузить два отдельных поста.

Пост 1:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

Пост 2:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: Дубляж
IMDb: tt0371746
```

В боте пользователь увидит выбор озвучки.

## 5. Как добавлять серии

Каждая серия загружается отдельным постом.

1 серия:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt3749900
```

2 серия:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 2
Озвучка: RHS
IMDb: tt3749900
```

## 6. Как проверить, что видео добавилось

После загрузки видео открой бота и проверь вручную.

Для фильма:

```text
Найти фильм -> Железный человек -> Смотреть в Telegram -> RHS -> видео отправилось
```

Для сериала:

```text
Найти фильм -> Готэм -> Смотреть в Telegram -> 1 сезон -> 1 серия -> RHS -> видео отправилось
```

Если нужной озвучки, сезона или серии нет в выборе, значит видео не добавилось или подпись заполнена неправильно.

## 7. Частые ошибки

### Нет IMDb

Неправильно:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
```

Правильно:

```text
Тип: Фильм
Название: Железный человек
Год: 2008
Озвучка: RHS
IMDb: tt0371746
```

### IMDb указан без tt

Неправильно:

```text
IMDb: 3749900
```

Правильно:

```text
IMDb: tt3749900
```

### У сериала нет сезона или серии

Неправильно:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Озвучка: RHS
IMDb: tt3749900
```

Правильно:

```text
Тип: Сериал
Название: Готэм
Год: 2014
Сезон: 1
Серия: 1
Озвучка: RHS
IMDb: tt3749900
```

## 8. Чеклист перед публикацией

Перед загрузкой проверь:

```text
[ ] Видео загружается в правильный закрытый канал
[ ] В подписи есть Тип
[ ] В подписи есть Название
[ ] В подписи есть Год
[ ] В подписи есть Озвучка
[ ] В подписи есть IMDb в формате tt...
[ ] Для сериала есть Сезон
[ ] Для сериала есть Серия
```

Если все пункты выполнены, видео должно появиться в Telegram-просмотре бота.
